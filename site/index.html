WHY AGENTPAGER

旧手机重新上岗

有人用开发板做任务状态栏。但屏幕、联网、声音、振动、触控……这些能力手机本来就有， 而且屏幕更好、系统更完整，还不用买新设备。于是有了 AgentPager。

[◎]

离开电脑也不错过进度

开始、思考、执行、完成、中断、等待批准、等待回答、离线——所有状态一目了然。

[▲]

重点任务自动置顶

需要你处理的任务自动置顶并展开，其他任务降低亮度，多任务并行也能快速找到重点。

[♪]

重要时刻主动提醒

像素动画、8-bit 音效和振动，让完成、中断与等待操作不再悄无声息。

[✓]

手机上直接批准 / 拒绝

Codex 发起权限请求时，无需切回电脑，在手机上点一下即可处理。

[⌬]

子代理进度同屏可见

父任务展示正在工作的子代理、耗时、最新步骤与 Token 用量。

[%]

额度余量随时可查

集中查看 Codex 5 小时与周用量窗口，不必等到触顶才发现。

QUEST START

快速开始 · 七步上岗

下载安装包

从 Releases 下载 APK（手机）和 DMG / EXE（电脑）。

打开电脑端 Bridge

启动 AgentPager Bridge，它驻留在 macOS 菜单栏 / Windows 系统托盘。

安装 Codex Hook

点击托盘图标选择「安装 Codex Hook」，原有配置会自动备份保留。

信任 Hook

Codex CLI 运行 /hooks 标记信任；Codex Desktop 在设置里点击信任。

显示配对二维码

打开「AgentPager 设置 → 连接」，屏幕出现配对二维码。

手机扫码配对

打开手机上的 AgentPager，扫一扫即完成局域网配对。

开跑

新建一个 Codex 任务，手机自动显示实时状态。任务完成。
