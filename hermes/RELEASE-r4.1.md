# AgentPager Windows r4.1：账号登录与自启动升级

本次只需更新 Windows Bridge。继续使用 r4 安卓 APK；浏览器扩展无需更新。

## Hermes 账号登录

1. 从托盘退出旧 Bridge，将新版解压到准备长期保留的目录，运行 `AgentPagerBridge.exe`。
2. 打开 **HERMES** 页，在上方填写 Hermes 服务 URL（含端口）、可选 Profile、你平时登录该 Hermes 网页服务的账号和密码，点击「登录」。不需要模型供应商 API Key。
3. 当前 NAS 服务已只读核对，支持 `basic` 账号密码认证；不要把密码发到聊天里。建议使用已有 HTTPS 入口；局域网 HTTP 仍会明文传输账号密码和统计。
4. 密码只用于当次登录，不保存、不回填、不自动重试。服务支持 `native_pkce` 时，程序通过 Hermes 原生授权码 + S256 PKCE 交换会话，再验证并用当前 Windows 用户 DPAPI 加密保存访问/刷新会话；不把普通网页登录 Cookie 冒充原生令牌。旧 Dashboard 保留经验证的兼容路径。会话失效时提示重新登录。
5. 高级手动令牌模式保留在折叠区域，只为兼容旧配置。退出按钮清除本机凭据，不声称撤销该账号在其他设备的登录。

Hermes URL、Profile、登录、用量连接及 PC 状态同步现已集中到 HERMES 页；总「设置」页只保留 Windows 启动、旧启动项处理和日志等通用项。NAS 不安装新插件，也不改变原有认证策略。

## 旧版自启动会不会重叠

- Bridge 的标准启动项使用同一个 HKCU Run 名称 `AgentPager`。新版手动运行时，仅将可识别且已获准的旧 Bridge 路径迁移到当前 EXE，不创建带版本号的第二项，也不重新启用被 Windows 禁用的启动项。
- 全局同桌面会话的单实例保护保留。若另一路径的旧 Bridge 还在运行，新版不会同时启动第二个 Bridge，会提示从托盘退出旧版后重试。
- 早期独立的网页监控程序可能另有启动快捷方式；当前电脑确实检测到两个。总「设置」页会提示，点击 **停用旧网页监控自启动** 后才备份并停用这些已知快捷方式。不会自动处理、不删除旧 EXE、不影响新版内置网页监控。
- 已经运行的旧程序不会因为停用自启动而自动退出；需要从它自己的托盘退出。尽量一直使用同一个固定解压目录，不要在压缩包中运行 EXE。

## 验证范围

- 账号登录、令牌提取及验证、自动续期、来源变更/退出竞争、密码不落盘、拒绝重定向、错误与限流、来源绑定、设置回滚：生产代码通过本地真实 HTTP fixture 与 Bridge 手机协议集成测试。
- 页签归属、登录控件、密码清空、状态独立、旧启动项提示与显式操作：静态 WPF 接线测试通过；真实 WPF Release 构建通过。
- 在用户 Windows PC 额外执行了隔离只读验证：真实生产 DPAPI 保存/重读/来源隔离/删除通过；只读检测原有启动项与两个旧网页监控快捷方式。未修改用户真实启动项、登录账号、连接配置或正在运行的应用。
- 未用用户真实账号密码执行 NAS 登录；未执行真实下一次开机自启动验收。实际网页登录密码请只在新版 HERMES 页输入。
