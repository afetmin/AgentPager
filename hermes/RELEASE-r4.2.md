# AgentPager r4.2 更新说明

本轮需要一起更新 Windows Bridge 和安卓 APK；ChatGPT 浏览器扩展不需要更新。保留现有 NAS 原生认证与统计读取方式，不安装 NAS 统计插件。

## 本轮调整

- Hermes 数据页只显示模型用量：第一行模型与占全部用量百分比，第二行 Token 数；移除“深度未知”、渠道和账号文字。同模型跨渠道合并，左侧前三不同模型，右侧 7/30/90 天仍为全部模型汇总。
- 数据页空闲轮播改为 15 秒。新版 Bridge 自动报告已启用来源；未安装 Claude 监控 Hook 的设备不再无条件显示 Claude。断线不等于关闭，已启用来源保留离线说明。没有来源或只有一个来源时不自动轮播；工作、子代理运行、等待批准/回答、后台、设置页和断线时暂停。
- ChatGPT 网页监控标题使用 `chatgpt网页 · 对话标题`，不改浏览器扩展。Hermes 使用会话所属 Agent 的显示名称，未自定义时使用其 Profile 名称；不把当前选中 Agent 的名称复制到其他 Agent 的会话。
- 子代理运行时，其所属父会话保持工作状态，并显示子代理工作文字；不把父模型停止输出或结束当前生成当作子代理已结束。只读取子代理计数，不转发目标、提示词或正文。

## 为什么上一版没有看到子代理状态

本轮对用户 PC 进行了只读核查：实际安装的 Desktop 状态脚本仍与 r2/r3 发布模板一致，没有 `subagent.roster` 和 `activeSubagents`。仅替换 Bridge EXE，不会自行改变此前安装的脚本。

r4.2 增加已安装状态集成的安全升级：识别已知发行模板，备份后原子替换；不会给未安装者自动安装，不会重新启用被关闭的插件，也不静默覆盖用户自定义脚本。此处是 PC 上原有 Desktop 会话状态集成，不是新的 NAS 插件。

## 升级步骤

1. 从 Windows 托盘退出旧 Bridge，把新包解压到长期保留的目录，运行新版 `AgentPagerBridge.exe`。不要同时运行不同目录里的 Bridge。
2. 到 HERMES 页查看状态集成的更新/连接提示。已知旧模板会安全升级；如果提示脚本被修改，则先检查修改内容，再决定是否通过原有安装/更新按钮手动替换。
3. 在安卓上覆盖安装新 APK，不要先卸载，以免丢失配对。若系统提示签名不一致，先停止安装并核对所装版本，不要通过卸载强行解决。
4. 检查数据页只有实际启用的来源；空闲时每 15 秒切页。让一个 Hermes 会话启动子代理，父生成结束后应继续显示子代理工作，其他空闲会话不应同时变成工作。
5. 早期独立网页监控程序不会因替换 Bridge 或停用自启动而自动退出；如仍在运行，可从它自己的托盘退出。不要同时使用旧独立网页监控和新版内置网页监控。

## 验证边界

自动化覆盖生产 Desktop 导出脚本、解析/状态目录、真实本地 HTTP 与手机 WebSocket 协议、虚拟时间轮播及 APK/WPF 构建。真实账号密码不参与测试，真实启动项不为测试而修改。安卓若没有连接设备，instrumentation APK 的成功构建不代表手机上的真机 UI 已执行验收。
